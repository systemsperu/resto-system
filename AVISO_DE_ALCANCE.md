# Aviso de alcance y uso

Este repositorio público contiene únicamente material académico preparado para el PA2. No concede acceso al proyecto privado completo ni contiene los elementos necesarios para reconstruirlo o desplegarlo.

Se excluyeron deliberadamente secretos, credenciales, datos personales, bases de datos, archivos de almacenamiento, configuraciones por cliente, historial Git del producto, integraciones externas y módulos ajenos al alcance declarado.

El contenido puede ser revisado como evidencia del trabajo académico. La publicación en GitHub permite descargar o copiar los archivos publicados; por eso solo se incorporó material que puede compartirse con el docente.
