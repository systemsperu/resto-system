# Alcance del repositorio

Este repositorio contiene el codigo fuente de RecreoSuite y el material academico de RESTO SYSTEM conservado en docs/diagramas y evidencias.

La publicacion del proyecto completo se realiza mediante una copia limpia del estado actual. No incorpora el historial privado anterior, que contenia archivos locales excluidos de esta entrega.

No se incluyen credenciales, archivos .env locales, certificados, respaldos de datos, almacenamiento de clientes ni dependencias instaladas. Cada instalacion debe configurar sus propios recursos segun AGENTS.md y docs/DEPLOYMENT.md.

La entrega conserva pendientes conocidos: una prueba de acceso del cajero al comprobante devuelve 403 y la ruta onboarding.exit contiene una referencia D::class que debe corregirse antes de una liberacion.
