# ADR 002: marca blanca configurable

## Decisión

RecreoSuite es el nombre técnico del producto. El nombre público, logos, colores, dominio, contenido y documentos provienen de la configuración del negocio.

## Consecuencia

PONOA, El Águila u otra marca no deben aparecer codificados en servicios, migraciones, rutas o vistas reutilizables.
